## About the Project

Nightlyfe is live and available for download on the [App Store](https://apps.apple.com/app/apple-store/id6444805357?pt=125817609&mt=8&ct=web), [Google Play Store](https://play.google.com/store/apps/details?id=com.nightlyfe.app) and on [nightlyfe.de](http://nightlyfe.de)

Nightlyfe was a start-up founded in 2023 developing a modern solution as web and mobile app (Android+IOS). This includes everything related to the development of a modern subscription based serviced tailored to serve thousands of customers simultaneously.

### Infrastructure

Infrastructure in Nightlyfe was setup to support varying workloads by utilizing modern, scalable solutions.

**Backend:**

- Postgres
- Python Django
- Automated Selenium Web Scraping
- Docker with K8s
- Portainer

**Frontend:**

- React Native (Android+IOS App)
- JavaScript Svelte Kit (Web App)
- Mapbox

As technical lead and co-founder I managed the full stack ranging from data acquisition and web scraping, database and backend to frontend on mobile and web.
